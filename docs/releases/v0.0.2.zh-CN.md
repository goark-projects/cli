# Goark CLI 0.0.2

[English](https://github.com/goark-projects/cli/blob/v0.0.2/docs/releases/v0.0.2.md) | 中文

发布日期：2026 年 9 月 7 日

Goark CLI 0.0.2 面向生产使用强化编译期生成、项目可移植性和源码质量边界。公开命令名称及
`goark.build` V1 模式保持不变。

## :lady_beetle: 问题修复

- 选择注解源码文件时遵循当前启用的 Go 构建约束。
- 所有替换输出通过校验前保留有效的旧版生成文件。
- 项目生成与 `goark codegen annotations` 统一采用拆分输出契约。
- 项目诊断准确报告生成包总数。
- 在本机及托管操作系统中统一解析规范项目路径。
- 新建项目固定引用 Goark 生态正式标签，并仅声明源码直接导入的模块。

## :package: 生成源码隔离

生成源码现在位于子包中，并按职责拆分：

```text
<package>/gen/zz_goark_core_gen.go
<package>/gen/zz_goark_properties_gen.go
<package>/gen/zz_goark_web_gen.go
<package>/gen/zz_goark_mvc_gen.go
```

该布局避免生成产物占用源码包的文件数和行数额度。Goark 会向 `.gitignore` 添加
`**/gen/`，原子写入文件，并且仅在所有权头确认文件由 Goark 创建时清理旧输出。

## :information_source: 升级说明

- 最低要求 Go 1.26。
- 生成子包引用的注解类型、注入字段、Bean 方法和 MVC 处理方法必须导出。
- 成功执行 `goark generate` 后，应删除已提交的旧版 `zz_goark_*_gen.go` 文件；生成的
  `gen` 目录是本地构建产物，不应提交。
- 未删除或重命名任何 `goark.build` V1 字段及公开命令。

## :white_check_mark: 验证

- `GOWORK=off` 下全量测试和竞态检测通过。
- 集成测试已基于 Goark 兄弟框架仓库编译生成项目。
- 公共代理烟测已对 App、Web 两类生成项目执行依赖整理和编译。
- `go vet`、`staticcheck`、模块校验、模块整洁检查和漏洞扫描通过。
- Windows、Linux、macOS 的 amd64、arm64 目标构建通过。

版本发布后使用以下命令安装：

```bash
go install goark.dev/cli/cmd/goark@v0.0.2
goark version
```

预期输出：

```text
goark 0.0.2
```

预编译归档尚未进行平台签名，并在 `checksums.txt` 中提供 SHA-256 校验和。
