# Goark CLI 0.0.2

English | [中文](https://github.com/goark-projects/cli/blob/v0.0.2/docs/releases/v0.0.2.zh-CN.md)

Release date: September 7, 2026

Goark CLI 0.0.2 hardens compile-time generation, project portability, and source-quality
boundaries for production use. Public command names and the `goark.build` V1 schema remain
unchanged.

## :lady_beetle: Bug Fixes

- Honor the active Go build constraints while selecting annotation source files.
- Preserve a valid legacy generated file until all replacement outputs pass validation.
- Apply the same split output contract to project generation and `goark codegen annotations`.
- Report generated package totals accurately in project diagnostics.
- Resolve canonical project paths consistently across local and hosted operating systems.
- Pin new projects to public Goark release tags with only directly imported modules.

## :package: Generated Source Isolation

Generated source now resides in a child package and is split by responsibility:

```text
<package>/gen/zz_goark_core_gen.go
<package>/gen/zz_goark_properties_gen.go
<package>/gen/zz_goark_web_gen.go
<package>/gen/zz_goark_mvc_gen.go
```

This prevents generated artifacts from consuming the source package's file and line budgets.
Goark adds `**/gen/` to `.gitignore`, writes files atomically, and removes stale output only when
the ownership header proves that Goark created it.

## :information_source: Upgrade Notes

- Go 1.26 or later is required.
- Annotated types, injectable fields, bean methods, and MVC handler methods referenced from the
  generated child package must be exported.
- Remove committed legacy `zz_goark_*_gen.go` files after a successful `goark generate`; generated
  `gen` directories are local build artifacts and must not be committed.
- No `goark.build` V1 field or public command name is removed or renamed.

## :white_check_mark: Verification

- Full tests and race detection pass with `GOWORK=off`.
- Integration tests compile generated projects against the sibling Goark framework repositories.
- Public proxy smoke tests tidy and compile both generated App and Web projects.
- `go vet`, `staticcheck`, module verification, module tidiness, and vulnerability scanning pass.
- Windows, Linux, and macOS archives build for amd64 and arm64.

Install after the release is published:

```bash
go install goark.dev/cli/cmd/goark@v0.0.2
goark version
```

Expected output:

```text
goark 0.0.2
```

Prebuilt archives are unsigned and include SHA-256 checksums in `checksums.txt`.
