# Goark CLI v0.0.1

English | [Simplified Chinese](v0.0.1.zh-CN.md)

V0.0.1 is the first public Goark CLI release. It establishes one deterministic project model around the official Go toolchain without replacing normal Go commands.

## Highlights

- One strict `goark.build` project descriptor next to `go.mod`.
- Generation-first `run`, `build`, `test`, `install`, `vet`, and `list` commands.
- Typed task graphs, external tools, lock files, project trust, caching, Profiles, dry runs, and read-only diagnostics.
- Deterministic compile-time generation for Goark DI, configuration, AOP, MVC, and Web integration.
- Simple `app` and `web` scaffolds; both include `goark.dev/gbc-log`.
- Transparent official Go access through `goark go ...`.
- English-first documentation with complete Simplified Chinese counterparts.

## Install

Go 1.25 or later is required.

```bash
go install goark.dev/cli/cmd/goark@latest
goark version
```

Expected output:

```text
goark 0.0.1
```

Use `@v0.0.1` instead of `@latest` only when this exact release must be reproduced.

## Start a Project

```bash
goark new demo
cd demo
go mod tidy
goark run
```

For a Web project:

```bash
goark new -type web -module example.com/admin -dir admin admin
```

## Compatibility and Boundaries

- Supported release targets: Windows, Linux, and macOS on amd64 and arm64.
- `goark.build` V1 intentionally excludes Agents and Plugins.
- `goark generate` runs Goark generators, not `go generate`; use `goark go generate` for official Go behavior.
- This is the first release, so no migration from an earlier Goark CLI release is required.
- Release archives provide SHA-256 checksums and are not platform-code-signed.

See the [CLI reference](../cli-reference.md), [`goark.build` reference](../goark-build.md), and [versioning policy](../versioning-and-releases.md) for the complete contract.
