# Goark CLI 0.0.1

English | [Simplified Chinese](https://github.com/goark-projects/cli/blob/main/docs/releases/v0.0.1.zh-CN.md)

Release date: September 6, 2026

Goark CLI 0.0.1 is the first public release. It provides deterministic project orchestration around the official Go toolchain while keeping normal Go commands directly accessible.

The release is available from [GitHub Releases](https://github.com/goark-projects/cli/releases/tag/v0.0.1). See the [changelog](https://github.com/goark-projects/cli/blob/main/CHANGELOG.md#001---2026-09-06) for the concise version history.

## :star: New Features

- Introduce `goark.build` V1 as the single, strict project descriptor alongside `go.mod`.
- Add generation-first lifecycles for `run`, `build`, `test`, `install`, `vet`, `list`, `fix`, and `generate`.
- Add typed task graphs with dependency validation, bounded concurrency, conditions, timeouts, cancellation, and `before`, `after`, and `finally` phases.
- Add isolated Go, system, and local tool resolution with project trust and deterministic `goark.build.lock` verification.
- Add content-verified task caching, safe variable expansion, secret redaction, and cross-process project locking.
- Add Profiles with deterministic Go argument and environment precedence.
- Add read-only project diagnostics, task inspection, graph output, tool management, shell completion, and the transparent `goark go ...` proxy.
- Add deterministic compile-time generation for Goark dependency injection, configuration, AOP, MVC, and Web integration.
- Add streamlined `app` and `web` scaffolds. Both include `goark.dev/gbc-log`; Web projects additionally include Arkarta and Arkhos integration.
- Keep the CLI executable standalone. Generated applications declare and manage their own Goark framework dependencies.

## :package: Distribution

Go 1.25 or later is required.

```bash
go install goark.dev/cli/cmd/goark@latest
goark version
```

Expected output:

```text
goark 0.0.1
```

Prebuilt archives are available for Windows, Linux, and macOS on amd64 and arm64. Verify every downloaded archive using the attached `checksums.txt`. Release archives are not platform-code-signed.

Use `@v0.0.1` instead of `@latest` only when this exact release must be reproduced or restored.

## :information_source: Compatibility and Upgrade Notes

- `goark.build` V1 intentionally excludes Agents and Plugins.
- `goark generate` runs Goark generators, not `go generate`; use `goark go generate` for official Go behavior.
- Project-aware commands require `goark.build` next to `go.mod`; `goark go ...`, `help`, `version`, `completion`, and `new` do not load it.
- This is the first public release, so no migration from an earlier Goark CLI release is required.
