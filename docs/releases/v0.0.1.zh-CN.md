# Goark CLI v0.0.1

[English](v0.0.1.md) | 简体中文

V0.0.1 是 Goark CLI 的首个公开版本。它围绕官方 Go 工具链建立唯一、确定性的项目模型，但不会替代正常 Go 命令。

## 核心能力

- 与 `go.mod` 同级的唯一严格项目描述文件 `goark.build`。
- `run`、`build`、`test`、`install`、`vet`、`list` 执行前固定生成代码。
- 类型化任务图、外部工具、锁文件、项目信任、缓存、Profile、dry-run 和只读诊断。
- Goark DI、配置、AOP、MVC、Web 集成的确定性编译期代码生成。
- 简单的 `app`、`web` 项目骨架，二者都包含 `goark.dev/gbc-log`。
- 通过 `goark go ...` 透明执行官方 Go 命令。
- 英文默认文档和完整的简体中文镜像。

## 安装

需要 Go 1.25 或更高版本。

```bash
go install goark.dev/cli/cmd/goark@latest
goark version
```

预期输出：

```text
goark 0.0.1
```

只有需要精确复现本版本时，才使用 `@v0.0.1` 替代 `@latest`。

## 创建项目

```bash
goark new demo
cd demo
go mod tidy
goark run
```

创建 Web 项目：

```bash
goark new -type web -module example.com/admin -dir admin admin
```

## 兼容性与边界

- 发布目标支持 Windows、Linux、macOS 的 amd64 和 arm64。
- `goark.build` V1 明确不包含 Agent 和 Plugin。
- `goark generate` 执行 Goark 生成器，不执行 `go generate`；官方 Go 行为使用 `goark go generate`。
- 这是首个版本，不需要从旧版 Goark CLI 迁移。
- 发布归档提供 SHA-256 校验和，但没有进行平台代码签名。
