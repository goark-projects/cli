# Goark CLI 0.0.1

[English](https://github.com/goark-projects/cli/blob/v0.0.1/docs/releases/v0.0.1.md) | 中文

发布日期：2026 年 9 月 6 日

Goark CLI 0.0.1 是首个公开版本。它围绕官方 Go 工具链提供确定性的项目编排，同时保留直接使用标准 Go 命令的能力。

本版本可从 [GitHub Releases](https://github.com/goark-projects/cli/releases/tag/v0.0.1) 下载。精简版本历史见[变更日志](https://github.com/goark-projects/cli/blob/v0.0.1/CHANGELOG.zh-CN.md#001---2026-09-06)。

## :star: 新功能

- 引入 `goark.build` V1，作为与 `go.mod` 同级的唯一严格项目描述文件。
- 为 `run`、`build`、`test`、`install`、`vet`、`list`、`fix` 和 `generate` 提供生成优先的固定生命周期。
- 提供类型化任务图，包括依赖校验、有界并发、条件、超时、取消以及 `before`、`after`、`finally` 阶段。
- 提供隔离的 Go、系统和本地工具解析，以及项目信任和确定性的 `goark.build.lock` 校验。
- 提供内容校验任务缓存、安全变量替换、密钥脱敏和跨进程项目锁。
- 提供 Profile 以及确定性的 Go 参数和环境优先级。
- 提供只读项目诊断、任务查看、图输出、工具管理、Shell 补全和透明的 `goark go ...` 代理。
- 提供 Goark 依赖注入、配置、AOP、MVC 和 Web 集成的确定性编译期代码生成。
- 提供精简的 `app` 和 `web` 项目骨架。二者都包含 `goark.dev/gbc-log`；Web 项目还包含 Arkarta 和 Arkhos 集成。
- CLI 可执行文件保持独立；生成的应用自行声明和管理 Goark 框架依赖。

## :package: 发布产物

需要 Go 1.25 或更高版本。

```bash
go install goark.dev/cli/cmd/goark@latest
goark version
```

预期输出：

```text
goark 0.0.1
```

提供 Windows、Linux 和 macOS 的 amd64、arm64 预编译归档。所有下载归档都应使用附件中的 `checksums.txt` 校验。发布归档尚未进行平台代码签名。

只有需要精确复现或恢复本版本时，才使用 `@v0.0.1` 替代 `@latest`。

## :information_source: 兼容性与升级说明

- `goark.build` V1 明确不包含 Agent 和 Plugin。
- `goark generate` 执行 Goark 生成器，不执行 `go generate`；官方 Go 行为使用 `goark go generate`。
- 项目感知命令要求 `goark.build` 与 `go.mod` 同级；`goark go ...`、`help`、`version`、`completion` 和 `new` 不读取该文件。
- 这是首个公开版本，不需要从更早的 Goark CLI 版本迁移。
